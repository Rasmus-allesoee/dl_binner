## Why implement the requested learner now

Independent evidence remains: the student starts fresh; the Oral proposal audit
finds 3,657/13,142 positive links with discordant provided origins, and poor native
biological neighborhoods persist. Shared DNA means discordant origin is not always
a false unique-sequence constraint. A larger network is not established as the
bottleneck. The [completed marker/source review](2026-10-25-dcvbin-efficiency-and-marker-learning.md)
and E011–E013 locus findings support reliable evidence and abstention, rather
than unconditional duplicate-family labels or a new external-tool campaign.

The new learner restores admitted online/EMA/predictor/buffer and Adam state,
uses a lower continuation rate, retains real same-parent views, and adds a soft
fixed-bootstrap anchor with more cautious signed proposals. The original proposal
denominator survives abstention, so removing uncertain positives does not increase
negative force. Lazy/missing Adam moments and unequal genuine step counters are
preserved. Original RNG was not saved, so fresh seed-11 continuation is explicit.
This is a coherent continuation bundle with extra exposure, not a pure loss test.

[BYOL](https://arxiv.org/abs/2006.07733v3) supplies primary precedent for stopped
moving targets and same-object views; it is an image-learning result, not evidence
of genome recovery. [Learning without Forgetting](https://arxiv.org/abs/1606.09282v3)
supports preserving a useful prior function while adapting; our unit-feature
anchor is a declared heuristic, not its classification method. These primary
abstracts were refreshed November 1. [SemiBin's current self-supervised source](https://github.com/BigDataBiology/SemiBin/blob/main/SemiBin/self_supervised_model.py)
was spot-checked for its explicit must-link/cannot-link loss only; the versioned
earlier project review remains the authority for detailed tool findings. No tool
run, runtime ranking or universal numerical confidence threshold follows.

The bridge is the one selective control. Do not add a loss grid. Implementing
learning in parallel avoids another coding-only delay, while ordering execution
prevents attributing a known construction gap to representation. If the bridge
supports a common policy change, freeze any learner-comparison amendment before
fits; do not select a constructor separately by dataset after scores.
