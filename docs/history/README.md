# Historical planning documents

This directory contains documents from the initial idea and planning phase of the project.

They are intentionally preserved because they contain useful context, reasoning, discarded alternatives, and early ideas.

They are **historical material only**.

They must not be treated as:

- current project requirements;
- a mandatory roadmap;
- a fixed learning curriculum;
- architectural commitments;
- implementation specifications;
- constraints that override newer evidence.

The current high-level project intent is defined in:

- `../../PROJECT_INTENT.md`

Agent behavior and document interpretation are defined in:

- `../../AGENTS.md`

The project is research-driven and intentionally dynamic. Current research plans and decisions should evolve as evidence accumulates.

If a historical document conflicts with newer project guidance or with research evidence, prefer the newer guidance and evidence.
