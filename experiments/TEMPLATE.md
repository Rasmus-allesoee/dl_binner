## Question and predictions

State the concrete claim, scope, alternatives, and observations that would support, contradict, or leave it unresolved. Explain why the experiment is useful now.

## Protocol

Describe the intervention, controls, native baseline configurations, and equal-input comparisons where needed. Link actual configuration and code. State primary and secondary metrics, definitions/denominators, success thresholds, repetition/seed policy, and comparison units before running.

## Data and information access

Link the input manifest: accessions/versions, hashes, sample/genome/contig IDs, transformations, source code, and retrieval/storage locations. Define train/development/evaluation roles, truth/recoverability, shared-sequence policy, reference/pretraining overlap, and information available to each method. Record unknowns explicitly.

## Execution and validation

Record the pre-existing executable Git commit, environment/container and database/model versions, exact command/resolved configuration, seeds, and hardware. State the smoke check, input/output integrity checks, time/resource limit, and stopping conditions. Link any preserved dirty-tree patch. For UCloud, include owner-run instructions and which outputs to return.

## Results and analysis

Link small tables/figures and analysis code, with exact input output-file identities. Include failures, timeouts, unassigned sequence, missing genomes, and uncertainty where relevant. Distinguish observed facts from interpretation. State which results use truth and which use estimates.

## Conclusion and next decision

State what was learned within scope, what remains uncertain, and why to keep, modify, or abandon the idea. Link updated Q/H records and any decision. A negative result belongs here, not only in a branch or chat transcript.

## Amendments and retention

Record dated protocol changes with reasons, especially after results were visible. If superseded, link the replacement. List external artifacts that must be retained, their hashes, and how to regenerate the rest.
