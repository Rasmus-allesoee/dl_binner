# E033: common BAM-derived multiscale information and representation

[Design](design.md) freezes the coherent information/learning bundle before new
community outcomes. [Operations](OPERATIONS.md) owns the separate execution
request, native gates and November 11 boundary. [Protocol](protocol.json),
[candidate](candidate-lock.json), [source](source-lock.json), [reuse](reuse-lock.json)
and [twenty BAMs](BAM-manifest.json) bind exact inputs/defaults. This experiment is
**locally implemented and tested; no community or cloud execution has occurred**.

The candidate preserves E031 state, adds measured parent/crop breadth/dispersion/
confidence to the explicit depth branch, and keeps E032's common constructor fixed.
All old features, models, truth, scores and failed journals remain immutable.
The prospective three-mode comparison is a bundle result, not a pure information
ablation. [Resource plan](resources.json) separates forecasts from native admission.
[Local evidence](local-observed.json) distinguishes actual checks from mocked or
unavailable paths. [Source review](../../docs/evidence/2026-11-04-multiscale-coverage-and-storage.md)
explains the measurement choice, JGI failure and deferred links/selection question.
[Cleanup](local-cleanup.json) records only obsolete caches and exact duplicates.
