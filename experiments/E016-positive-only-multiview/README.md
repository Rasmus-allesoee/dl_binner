## Strategic purpose and alternatives

Positive-only learning addresses a concrete untested training assumption at low
incremental cost; simply increasing network size does not address it. E015 did not
show that negative pairs caused poor recovery. This is the last currently planned
loss control, not a default series of small weight experiments. Use its recovery,
parent/refinement interactions and population/geometry diagnostics to choose the
next coherent block. If recovery remains weak, consider the serious broader routes
already reviewed: raw/learned/depth-aware genome grouping, reliable marker-informed
training, window/context aggregation or frozen GLM/head/hybrid information. Do not
pick a Transformer solely because strong whole tools use one; do not reject GLMs
because an older short-neighbor screen was mixed. A broader information upgrade
is justified if the retained evidence identifies information/discrimination limits;
another small follow-up is justified only if one unresolved contract can change
that design decision. Both current communities are development.
