# E006: Installed generic command usability

Prepared 2026-10-06. Status: **planned**; scientific utility is not assessed here.
The [protocol](protocol.json) freezes software, recovery, fixture and resource
contracts before measured integration. [D011](../../docs/decisions/D011-first-binner-prototype.md#e005-acceptance-and-next-bounded-usability-milestone-2026-10-06)
and [PROTOTYPE](../../docs/PROTOTYPE.md#prepared-next-milestone-one-end-to-end-command)
authorize this bounded product milestone. E005 remains accepted without reruns.

The installed `dl-binner run` packages unchanged defaults and a serial native
Snakemake DAG. A separate existing Snakemake 9.16.3 Python is explicit; no
installation, AMBER, experiment locators or labels enter the generic command.
Eight stages prepare/train/raw embed/cluster/export/learned reload/cluster/export.
Successful stages publish from unique staging directories and receive hash-bound
receipts. Partial failures retain logs/files. Resume first verifies input, source,
configuration, environment and completed bytes; unreceipted final outputs are
refused, never silently repaired. Checkpoint parity and complete DNA export are
required; biological superiority is not.

Native software integration will use a new versioned local environment and built
wheel from outside the checkout. New deterministic windows of retained GI DNA
plus explicitly synthetic depth/ambiguity cases supply ≤32 contigs / 0.6 Mb.
The suite's timed integration is capped at two hours, four threads, interop one,
loader zero and 8 GB sampled working RSS. Setup/checks are separately accounted.
No native scientific worker may be mocked. Scheduling/supervisor-only fixtures
may use tiny sleeping/failing processes; their scope will be named. Native Mac
checks do not establish corrected generic-launcher Linux validation.

Retained E005 output accounting will be inspected through the new label-free
summary reader, without feature extraction, model inference, clustering or AMBER.
Summary JSON/TSV retain both arms, all six strata, masks and reasons. Bin size and
assignment are not purity, genome recovery, completeness or MAG quality.

Source/input/wheel/runtime hashes, commands, logs, failed attempts and small
observations will be retained under `artifacts/e006-cli-usability/` with a compact
committed receipt after review. Existing environments/caches remain read-only.
